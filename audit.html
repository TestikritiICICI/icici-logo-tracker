How the audit was done

What was checked, and what was not

Covered

  • Top 20 partner brands from the ICICI Bank Festive Bonanza page
  • Each brand's homepage or offers page on desktop web
  • One product, buy, restaurant or hotel page per brand
  • Page-code scans for "icici" in image names, alt text and page text, plus screenshots

Not covered

  • Checkout and payment pages, which need a sign-in or a booking
  • Brand mobile apps
  • Tata CLiQ and Reliance Digital product pages have text scans only, no screenshots

18. Public website on Render, daily run on GitHub Actions

  • Public link: https://icici-logo-tracker.onrender.com (Render free static site icici-logo-tracker, workspace iKriti). Hidden from search engines (noindex), but open to anyone with the link.
  • Code and data: https://github.com/TestikritiICICI/icici-logo-tracker (public repo).
  • .github/workflows/daily-check.yml runs every day at 03:30 UTC (9:00 AM IST) on GitHub's servers, with no Mac or person needed. It runs the check with Chromium and Tesseract OCR, saves results.json to main, rebuilds the website and force-pushes it to the site branch. Render redeploys automatically on each push to site. A "Run workflow" button on the Actions tab starts a run by hand.
  • The workflow file is written as one-line JSON (valid YAML) because it was added through the GitHub web editor; the Mac's saved GitHub login cannot push workflow files.
  • Changes for servers: OCR falls back to Tesseract when not on a Mac; Chromium is used instead of Google Chrome; ICICI logos are bundled in assets/; screenshots are kept on the site for the last 30 days (results are kept for all days).
  • Screenshots are not stored in main; each run restores the last 30 days of screenshots from the site branch.
  • The Mac scheduled task (icici-logo-daily-tracker-2) is now a duplicate of the GitHub run.

20. Mac fills the gaps (GitHub plus Mac)

  • The user chose to keep GitHub's daily 9:00 AM run and have the Mac improve it when it is on.
  • scripts/mac_fill_gaps.sh: waits for any GitHub run in progress, pulls GitHub's results and the screenshots from the site branch, checks every brand from the Mac, retries failures, rebuilds the site, pushes results to main and publishes the site branch.
  • Merge rules in scripts/daily_check.py: the Mac's results replace the server's for that day; a brand the Mac cannot load keeps the earlier result (shown on the site as "result from earlier run"); the GitHub run never overwrites a day the Mac has already checked. Each day records run_by ("Mac in India" or "GitHub server").
  • Why a full Mac check, not just the blocked brands: the server's Tesseract OCR missed ICICI logos inside banners that the Mac reads (Amazon, Sleepyhead and Croma all showed the logo from the Mac on November 20 but not from the server).
  • November 20 after the Mac check: 14 ICICI logo shown, 2 text only, 16 other banks only, 58 no bank shown, 4 could not be checked (Ajio, Goibibo, MakeMyTrip, WearKatha), 8 website needed. Live on https://icici-logo-tracker.onrender.com.
